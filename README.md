# VocalRoute AI

Powerful voice navigation and AI assistance for modern web applications.

VocalRoute allows users to navigate your Next.js application using voice commands. It handles transcription, intent resolution, and navigation entirely in the browser, providing a fast and private user experience.

## Repository Structure

-   `packages/sdk`: The core SDK (`@vocalroute-ai/sdk`) for React/Next.js applications.
-   `docs`: Documentation and integration guides.

## Installation

```bash
npm install @vocalroute-ai/sdk
# or
yarn add @vocalroute-ai/sdk
```

## CLI Usage

The VocalRoute CLI helps you manage your route registry and AI intents.

```bash
npx vocalroute scan
```

### Advanced Options

| Option | Description |
| :--- | :--- |
| `scan` | Base command to scan your project for routes and generate a registry. |
| `--ai` | Use LLM to generate more natural and diverse intents for each route (requires `OPENAI_API_KEY`). |
| `--skip <segments>` | Comma-separated list of dynamic segments to skip in logical paths (e.g., `locale,shopId`). |
| `--help` | Show all available commands and options. |

**Example:**
```bash
# Skip structural segments (like [locale]) to group logical pages
npx vocalroute scan --skip locale

# Use AI to generate diverse intents
npx vocalroute scan --ai
```

## Setup

### 1. Initialize Provider

Wrap your application in `app/layout.tsx`. Import the required CSS and provide the generated route registry.

```tsx
// app/layout.tsx
import "@vocalroute-ai/sdk/vocalroute.css";
import { VocalRouteProvider } from "@vocalroute-ai/sdk";
import { staticRegistry } from "../vocalroute/registry"; // Generated by CLI

export default function RootLayout({ children }) {
  return (
    <VocalRouteProvider routes={staticRegistry} showButton={true}>
      {children}
    </VocalRouteProvider>
  );
}
```

## Configuration

### VocalRouteProvider Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `routes` | `RouteRegistry` | `[]` | The generated route registry. |
| `showButton` | `boolean` | `false` | Whether to show the built-in trigger button. |
| `showOverlay` | `boolean` | `true` | Whether to show the built-in voice overlay. |
| `aiConfig` | `Object` | - | Configuration for AI model and fallbacks. |

### AI Configuration (`aiConfig`)

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `enabled` | `boolean` | `false` | Enable cloud-based AI intent resolution. |
| `openaiApiKey` | `string` | - | Your OpenAI API Key. |
| `intentModel` | `string` | `gpt-4o-mini` | The model used for mapping speech to route intents. |
| `fallbackToLocal` | `boolean` | `true` | Falls back to browser-only matching if AI resolution fails. |

## Features

-   **Zero-Config Route Discovery:** Automatically maps your Next.js `app` or `pages` directory.
-   **Local processing:** Intent resolution happens in the browser—fast and secure.
-   **Premium UI:** Real-time volume-reactive animations and a modern voice overlay.
-   **TTS Integration:** Conversational replies for navigation status and AI responses.
-   **AI-Powered Intents:** Optional LLM integration for handling diverse natural language queries.
